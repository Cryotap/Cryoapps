Frequently asked questions

How do I update Rusty?

Download the newest version from the download page and install it over the old one. Your data is kept.

"App not installed" appears when I update

This happens when the installed copy was signed with a different key. Back up your bookmarks first (Settings → Downloads and data → Back up), uninstall the old copy once, then install the new one.

How do I use the VPN?

Rusty connects to a WireGuard server that you provide. Import your .conf file from the VPN button in the menu, then turn it on. Rusty does not supply VPN servers.

How do I install extensions?

Open an extension's page on the Chrome Web Store inside Rusty and tap the install banner. Extensions that rely on background pages or pop-ups are not supported.

How do I delete my data?

Open Settings and use the clear data options, or uninstall the app. Rusty has no accounts and keeps no data about you on any server. See the privacy policy.

A website doesn't work properly

Try turning off the ad blocker for that site from the padlock menu, switching to desktop site, or reloading. Tell us the address and we will take a look.
